# SuverLiteBox — минималистичная тема для WordPress 🚀

> Самая простая и быстрая тема на свете! Без лишнего кода, только необходимые функции.

## Описание

Эта тема создана для тех, кто ценит скорость загрузки и простоту. Она не перегружена плагинами или тяжелыми библиотеками стилей. В основе лежит чистый HTML5/CSS3/PHP, что обеспечивает отличную производительность.

*   **Минимум файлов:** Только то, что действительно нужно.
*   **Адаптивность:** Работает на любых устройствах без дополнительных скриптов.
*   **Фиксированная шапка:** Меню всегда под рукой.
*   **Бургер-меню:** Плавное открытие меню на мобильных устройствах.
*   **Поддержка миниатюр:** Для красивых анонсов постов.

### Как установить тему:
1.  Скачайте архив с темой из репозитория.
2.  Войдите в админ-панель вашего сайта → Внешний вид → Темы → Добавить новую → Загрузить тему.
3.  Выберите скачанный архив и нажмите «Установить».
4.  Активируйте тему.

---

## Настройка

После активации выполните следующие шаги:
- **Меню:** Перейдите во вкладку *Внешний вид > Меню*. Создайте новое меню и назначьте его в качестве основного (`Primary Menu`).
- **Сайдбар:** Во вкладке *Внешний вид > Виджеты* перетащите нужные блоки (*Архивы*, *Свежие посты*) в область `Основной`.
- **Миниатюры:** Миниатюры записей включаются автоматически через функцию поддержки в теме. Просто добавьте изображение при создании поста.

### Структура папки темы:
suver-lite-box/  
|-- index.php # Главная страница / Архивы  
|-- comments.php # Страница комментариев  
|-- sidebar.php # Область для виджетов  
|-- style.css # Основной стиль (с reset)  
|-- functions.php # Поддержка функций WP

## Рекомендации по оптимизации

Для максимальной скорости рекомендуется:
- Использовать CDN для шрифтов Google Fonts вместо прямой ссылки.
- Сжимать изображения перед загрузкой.
- Подключить кэширующий плагин (например, *WP Rocket*).

Если вы хотите изменить дизайн, все стили находятся в одном файле `style.css`. Вы можете легко редактировать цвета, отступы и типографику.
