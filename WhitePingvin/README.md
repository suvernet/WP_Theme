## Whitepingvin Blank Theme

Минималистичный скелет темы WordPress. Только суть, без лишнего.

### 📥 Скачать
Нажмите **Code → Download ZIP** на главной странице репозитория.

### 👁️ Посмотреть
Изучите структуру файлов прямо в браузере:  
`WP_Theme/WhitePingvin/whitepingvin_blank`

### 💾 Установить
Распакуйте архив, возьмите только папку `whitepingvin_blank`, заархивируйте её и загрузите в WordPress.
